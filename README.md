# Used Car Price Prediction Using ANN

## Project Overview
This project predicts the selling price of used cars using an Artificial Neural Network (ANN).

## Objectives
- Analyze used-car data using SQL.
- Preprocess numerical and categorical features.
- Build and train an ANN regression model.
- Evaluate predictions using MAE, RMSE, and R².

## Technologies Used
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas and NumPy
- MySQL
- Jupyter Notebook

## Workflow
1. Data collection and SQL analysis
2. Data preprocessing
3. Feature engineering
4. ANN model training
5. Model evaluation

## Future Improvements
- Compare different model architectures.
- Improve feature engineering.
- Build a web application for price prediction.
